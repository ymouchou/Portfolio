# Présentation des TP ou mini-projets réalisés durant ma formation en BTS SIO:


## Première année de BTS SIO :

- AP Cinema : Durant ce projet j'ai du réaliser un site qui répertorie des films en fonction de catégorie, et de filtres. Pour ce faire j'ai du faire une API pour pouvoir faire en sorte que les films soient bien classés en fonction des critères et qu'ils puissent changer automatiquement sans devoir modifier le code (nottament avec le filtre "Films du moment").

- Jeu tour par tour : J'ai réalisé un mini-jeu tour par tour. Pour réaliser cela, j'ai utilisé le langage Python en faisant de la programation orientée objet. J'ai créé différentes classes nottament pour les attaques, les types de personnages, l'énergie, etc.
